ERD-DRIVEN WEBSITE UPDATES

Key data relationships reflected in the mockup

Subscription Plan → Subscription

Plans describe what Apex offers; subscriptions show the plan each member is actively using.

Subscription → Payment

Payment records now belong to a member's subscription, which supports a cleaner account and billing view.

Employee → Trainer → Class

Trainers are shown as specialized employees who lead individual classes.

Member → Class Registration / Waiting List

Members can be associated with registered classes and separate waitlist entries when a class is full.
