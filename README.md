# Apex Performance Revised Website Mockup

This folder contains the updated Apex Performance coded website mockup.

The mockup was revised so the site structure and content better reflect the **revised ERD**.

## Included pages and functions
- Home
- Classes, trainers, registrations, and waitlist view
- Subscription plans and active subscription view
- About page with business, employee, and trainer information
- Member portal with subscription details, payment history, registered classes, and waiting-list entries

## Revised ERD items reflected in the mockup
- `Subscription_Plan`
- `Subscription`
- `Payment`
- `Employee`
- `Trainer`
- `Class`
- `Class_Registration`
- `Waiting_List`
- `Member`
- `Business_Information`

## Design notes
- Payment transactions are still handled by a third-party provider.
- Cancellations are still handled by a third-party provider.
- The mockup displays information only; it does not connect to a live database.
- Status values are presented with readable text rather than color alone.
