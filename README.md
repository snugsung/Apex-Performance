# Apex Performance Step 2a Mockup

This folder contains a coded website mockup for the Apex Performance Step 2a assignment.

## Included pages and functions
- Home
- Classes and availability
- Membership information
- About page
- Member account / billing status

## Interview items reflected in the mockup
- Search
- Class schedules
- Class availability
- Waitlist option
- Billing status
- In-person account setup
- Third-party payment and cancellation handling
- Membership discounts for educators, first responders, military, and retirees
- About page with client/company information
- Responsive layout
- Accessible labels and text-based status wording
- No merchandise sales
- No reports or dashboards for members

## Files
- `index.html`
- `styles.css`
- `app.js`
- `assets/apex-performance-logo.png`

Open `index.html` in a browser to review the mockup.
